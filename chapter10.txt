The 14-Lab Method (Recap)
Every worklet in this book is built the same way: as a coordinator-plus-workers agentic system that is grown, one capability at a time, through 14 hands-on labs. This chapter is self-contained — it restates the method, the node-graph legend and the pseudocode conventions before applying them to this worklet — so it can be handed to a team on its own.
The guiding design principle is constant across all worklets: agents draft and flag; a named human approves. No worklet takes a consequential action autonomously — the human authority named in this chapter signs off before anything is published or sent.

10.1  Worklet Overview
Students discover 8th-semester full-time internship opportunities through scattered word-of-mouth and outdated notice boards; eligibility is checked manually; and once a student leaves, the department has no live view of their progress for the rest of the semester.
This worklet proposes an Internship Application & Tracking Portal that surfaces matched opportunities, verifies eligibility, processes applications and approvals, tracks progress through the full semester, and compiles a final evaluation — turning a scattered process into one auditable record from opportunity to final grade.
Stakeholders: Students, Faculty Mentors, Internship Cell, HoD
Problems heard
Students discover internships through scattered word-of-mouth and outdated notice-board postings.
Eligibility (CGPA, backlog, credits) is checked manually and inconsistently before approval.
Once a student leaves for a full-time internship, the department has no live view of their progress.
Final evaluation depends on last-minute paperwork with no audit trail back to reports or check-ins.
Approvals across mentor, HoD, and Internship Cell are not consistently recorded.

10.7  Solution Paradigm — Pseudocode
Orchestrator (the whole run)
function run_internship_application_tracking_portal(request):
    ctx = Coordinator.new_run(request)        # isolated, checkpointed
    plan = Coordinator.build_plan(request)     # locked before work begins
    ctx = OpportunityDiscoveryAgent.step(ctx, plan)
    ctx = EligibilityVerificationAgent.step(ctx, plan)
    ctx = ApplicationProcessingAgent.step(ctx, plan)
    ctx = ApprovalAgent.step(ctx, plan)
    ctx = ProgressTrackingAgent.step(ctx, plan)
    ctx = EvaluationAgent.step(ctx, plan)
    ctx = FacultyMentorInternshipCellHoDReview.step(ctx, plan)
    report = ValidationAgent.validate(ctx, plan)   # hard gate
    while not report.passed and attempts < MAX:    # self-healing (Lab 10)
        Coordinator.regenerate(report.failing); report = validate(ctx, plan)
    draft = assemble(ctx)                          # the tracked internship application
    decision = TheGate.review(draft)  # HUMAN — final authority
    if decision.approved:
        final = apply(decision.edits, draft)
        Governance.publish(final, version=next()); Audit.log_all()
    return final

Validation (the acceptance gate)
function ValidationAgent.validate(ctx, plan):
    checks = [
      ('deadlines are tracked accurately', test_0(ctx, plan)),
      ('eligibility is enforced', test_1(ctx, plan)),
      ('no submission happens without student approval', test_2(ctx, plan)),
      ('status changes are audited', test_3(ctx, plan)),
    ]
    failing = [n for n,ok in checks if not ok]
    return Report(passed = not failing, failing = failing,
                  diagnosis = explain(failing))

Connector (one governed surface for all sources)

    read('the application-status feed')
