Lab 7 — Agentic Node Graph
Concept: Graph-based orchestration (LangGraph)   ·   Reference worklet: campus app graph: requirement → design → release
1.  Concept applied in your worklet — what you used and where
Modelled the internship application workflow as a LangGraph StateGraph: ingest → planner → discovery → eligibility → application → validation → human gate → publish, with bounded retry.
2.  Technical stack — languages, frameworks, libraries, APIs, models, tools
Official LangGraph StateGraph, TypedDict state, MemorySaver checkpointing, SQLite workflows, Python backend/API, and InternTrack Human Gate UI.

Validation conditionally routes to pass, bounded retry, or escalation. The graph pauses at the Coordinator gate using a checkpoint; approval resumes the same graph and publish commits the canonical workflow.
4.  Evidence — repo link / screenshots / demo / sample output
Live Lab 7 LangGraph Studio and verification suite: real StateGraph, checkpoint pause/resume, Coordinator-only approval, rejection reason, bypass protection, and 9/9 Lab 7 tests passed.

Lab 8 — Parallel Swarm
Concept: Parallel execution, swarms & fault-tolerant merge   ·   Reference worklet: hackathon planner: 4 role agents + a merge step
1.  Concept applied in your worklet — what you used and where
Used a parallel swarm to evaluate up to four internship preferences concurrently, merge all worker results, rank opportunities, and then wait for Coordinator approval.
2.  Technical stack — languages, frameworks, libraries, APIs, models, tools
Official LangGraph StateGraph, MemorySaver, parallel Pregel workers, Annotated list reducer with operator.add, SQLite eligibility/vacancy checks, REST API, and Human Gate UI.
3.  Implementation — what you built and how it works (key steps / architecture)
split → 4 parallel workers → fan-in reducer → eligibility/vacancy ranking → Coordinator gate. Worker failures are isolated as WORKER_ERROR; approval resumes the same checkpoint into the commit node.
4.  Evidence — repo link / screenshots / demo / sample output
Live Lab 8 demo shows four parallel branches, real DB eligibility/vacancy data, ranking, and Coordinator Human Gate. Dedicated Lab 8 suite: 13/13 passed; Labs 1–7 regression passed.
